Fill in the role. The model compares it against ~50,000 real STEM compensation reports to estimate base pay — not bonus, not stock.

Gender and race are included because the underlying survey collects them and the model was trained on the full feature set. They are not a recommendation to use these factors in real pay decisions — see the README for the full discussion of this tradeoff.
